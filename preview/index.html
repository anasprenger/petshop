PetCare

Pré-visualização interativa

Use o app como no celular: navegue pelas abas, abra os detalhes e teste o cadastro, a edição e a exclusão de animais e serviços.

Dados de exemplo

Os animais e serviços desta página são fictícios e ficam só na memória do navegador. O app real usa a API REST (Node.js + Express) com o banco MySQL.

Experimente

  • Toque nos cartões do resumo para abrir a lista filtrada.
  • Salve um cadastro com campos vazios para ver a validação.
  • Exclua um animal com serviços: o histórico dele sai junto.
